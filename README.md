# Lite Stick Fighters

A small children's **Flash game**: articulated paper-doll style characters (the kids **Pili**, **Raquel** and the simple stick figure **Stick**) built from separable body-part graphics (`piezas/`), with each character shipped as an editable `.fla` / compiled `.swf` pair. A XML manifest (`players.xml`) lists the playable characters, and the final game was compiled as a **Windows Flash projector** (`juego.exe`).

> **This project is shared ONLY for educational purposes. Its use, direct or derived, for professional or economic purposes is not permitted.**

**Note on security**: for security reasons, some parts of the project are not published here (personal photo reference material present in the original folder).

## Requirements / How to run

- **Ready to play**: the packaged game is attached as a **GitHub Release asset** (`juego.zip`).
- **Editing**: `.fla` projects require **Adobe Flash Professional / Animate** (CS era); code and body pieces are edited inside the FLA and published to `.swf`.
- Playback of the `.swf` outputs requires the discontinued **Adobe Flash Player** (or the included Windows projector build). Flash is end-of-life, so these artifacts are kept for historical/educational reference only.
- `players.xml` declares which `.swf` characters are available in the game.
